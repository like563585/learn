# Valhalla 项目概述

## 项目简介

**Valhalla** 是一个开源的 C++ 路由引擎，基于 OpenStreetMap 数据，支持：
- 🛣️ 转向转向导航（Turn-by-turn routing）
- 📊 时间/距离矩阵计算（Time-distance matrix）
- 🎯 等时线计算（Isochrones）
- 📍 地图匹配（Map matching）
- 🧮 高程查询（Elevation sampling）
- 🚗 多模式路由（车、自行车、行人、公共交通）

## 技术栈

| 项目 | 比例 | 说明 |
|------|------|------|
| C++ | 94.5% | 核心引擎 |
| Python | 2.2% | 绑定接口 |
| CMake | 1.2% | 构建系统 |
| Lua | 0.9% | 标签处理 |
| Shell | 0.5% | 脚本工具 |

### 核心依赖

- **Boost** — 容器、线程、日期时间
- **Protobuf** — API 请求/响应格式定义
- **RapidJSON** — JSON 解析
- **date/tz** — 时区处理
- **libosmium** — OSM 数据解析
- **SQLite3 + SpatiaLite** — 空间数据库
- **GEOS** — 几何运算
- **LuaJIT** — 标签优先级计算
- **libprime_server** — HTTP 服务框架
